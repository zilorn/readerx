# 共用抽屉

抽屉外壳统一使用 `src/components/Drawer.tsx`，目录、书签、批量下载、章节范围、
阅读设置、正文编辑、听书、搜索、文本替换、段落注释、书架 / 书源分组、导入、书籍信息与 WebDAV 配置共用此实现。
书源删除确认与网址导入也使用同一外壳。

`Drawer` 负责遮罩点击、面板定位、动画、圆角 / 阴影、层级与对话框语义。
标题、关闭按钮、滚动区、表单与操作按钮由业务组件提供；业务数据、关闭限制与状态重置留在业务组件中。

- `label`：已翻译的对话框名称；`onClose`：遮罩点击时的关闭回调，可按忙碌状态拒绝关闭。
- `position`：默认 `fixed`；阅读器内部的抽屉使用 `absolute`，相对阅读区定位。
- `layer`：遮罩层级，默认 50，面板使用下一层。嵌套抽屉需高于其父抽屉。
- `sizeClass`：底部面板高度约束，默认 `max-h-[72%]`，可指定固定高度或其他最大高度。
- `placement`：默认 `bottom`；桌面目录传入 `right`，切换为右侧栏与较浅遮罩。
- `readerUi`：为遮罩与面板添加 `data-reader-ui`，阻止阅读器将浮层操作识别为阅读手势。
- `panelRef`：获取面板元素，例如供桌面目录边缘悬停逻辑使用。
- `class`：补充内容样式，例如禁止选择文本或面板内边距。

调用方用 `Show` 管理挂载；需要挂到 `document.body` 时仍由调用方使用 `Portal`。
保活页面继续通过 `closeOnRouteChange` 收起浮层。底部面板统一按 `--app-column` 限宽并居中。
全屏文档页、居中确认弹窗与无模态遮罩的批量操作条不使用抽屉外壳。

## 章节正文编辑

阅读设置的「编辑正文」打开 `ChapterEditSheet`，以书库原章的 `chapterUnits`
展开文本，不将文本替换或简繁转换结果写回。正文未就绪、重载或目录检查期间禁用入口。
每行保存为一个文本块；未改动的小标题保留层级，修改的小标题按普通段落保存。
块图和段内图引用始终保留，锚点按原文与草稿的共同前后缀映射；
删除的文字区域内的图片收敛到编辑区域开头，尾部块图仍保留在正文之后。

保存先显示「保存后，先前内容会失效，无法找回」确认；取消确认直接丢弃草稿，
失败保留草稿供重试。确认后通过 `updateBookChapters` 在本书写队列内复核
章节 cid、地址和原文，发生变化时拒绝覆盖并提示重新打开；图片下载的最新本地引用
从队列内的最新章节合并。仅回写正文，沿用 Rust 按 cid 的 SQLite 事务与指纹重算，
不新增旧正文副本或数据格式。保存成功重新分页并回到本章开头。

编辑抽屉打开时停止听书，暂停自动翻页、翻页快捷键、音量键和桌面贴边菜单；
Android 返回和 Escape 关闭并丢弃草稿，保存期间拒绝关闭。
正文变化可能让原书签或段落注释失去定位，确认提示同时说明这一点。
回归检查：`node scripts/chapter-editing-test.mjs`。
