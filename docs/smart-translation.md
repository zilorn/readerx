# 智能翻译

应用「设置 → 智能翻译」的总开关默认关闭，打开后可进入配置页。
阅读设置里的「本书智能翻译」单独保存本书覆盖项，未修改项实时沿用全局；
「恢复全局默认」清除覆盖项。总开关关闭会停止任务并隐藏译文，保留缓存。
本地及 WebDAV 新书导入后进行有界采样：至少 80 个字母/文字，汉字占比低于 50%
或含日文假名时自动启用；其余书籍保持关闭。已有书可在阅读设置中手动开启。

## 阅读与服务

- 选区菜单「翻译」直接使用所选纯文本；浮窗提供加载、错误重试与复制译文。
  折叠模式在段落右侧提供相同浮窗入口，仅在点击展开时翻译该段，未命中缓存才请求；
  折叠期间忽略预翻译章数，不自动翻译当前章或后续章节，也不提前生成术语表。
  已保存的预翻译配置在切回内嵌双语或仅译文模式时继续生效。顶部四行规则复用
  `selectionMenuPosition.ts`，弹窗受安全区约束，翻页、换章、滚动或返回键收起。
- 双语模式在原段落下以 88% 字号、次要颜色显示译文；仅译文模式在译文到达前
  保留原文，到达后替换显示；原文模式不请求。标题、图片及保守判定已是目标语言
  的段落不生成译文。图文混排保留图片。
- 「显示模式」只控制双语、仅译文、原文排版；折叠译文开关仅在双语模式显示，隐藏时保留偏好。
  「阅读文本」独立选择听书使用原文还是译文，三种显示模式下都可切换，不改变页面排版。
  阅读设置保存本书 `readingText` 覆盖项；全局设置和翻译配置页修改默认值，未覆盖书籍实时跟随。
  旧配置缺少该字段时默认朗读原文，不把既有显示模式解释为听书偏好。
  译文听书按播放章逐句翻译，沿用本书服务、目标语言与术语表；原生和 HTTP 引擎、播放预取、
  用户主动触发的音频预热均使用所选文本。只有进入听书后才请求，不因切换偏好自动翻译全书。
  切换文本保留当前原文句子位置与暂停状态，停止、切章、离页和配置更新取消未完成的翻译。
- 译文参与真实 DOM 测量、长段分页与滚动高度计算，不改变存盘正文；书签、注释、
  搜索及听书高亮仍使用原文镜像。阅读进度保留原文坐标，译文内部按段内比例映射。
  同章重排前取消旧翻页动画并捕获位置，沿用 `resumeTarget/applyResume` 恢复。
  滚动采样同时记录视口实际命中的原文/译文节点，节点类型仅随本次恢复目标保留；
  后续批次到达时回到正在阅读的一侧，不能用同段是否已有译文判断。
  恢复期间用透明度隐藏并暂停正文交互，避免同步重建节点残留隐藏状态造成空白。
- 默认 Google 公开端点无需密钥，地区可达性和速率无保证；失败时可重试或切换服务。
  AI 支持 OpenAI、DeepSeek、自定义 HTTP(S) Base URL、模型、密钥、思考强度，
  可选择 Chat Completions 或 Responses；Base URL 自动补协议路径，也允许完整路径。
  AI 接口需接受 JSON object 输出，返回段落编号与译文；拒绝缺项、重复编号或空译文。
- 每批最多 15 段，共享并发预算 1~8；当前阅读位置附近优先。默认只翻当前章，预翻译
  可选后续 1~5 章，在线章正文随现有阅读窗口到达后继续，不发起整本翻译。
  429/5xx 最多额外重试两次；每次请求（含读响应）90 秒超时，关开关/离页取消任务。

## 术语表

启用后在首次 AI 翻译前生成按书术语表；Google 不支持 AI 术语表，会提示切换 AI。
采样至多 12 个分布于首、中、末的章节，每章头/中/尾各 500 字符，合计约 18,000 字符，
不发送整本。条目覆盖术语、人名、地名及专有名词，最多 200 条，备注最多 29 个字符。
阅读设置直接提供「翻译前生成 AI 术语表」开关，保存为本书覆盖项。
「书籍详情 → 本书术语表」及「翻译管理 → 本书术语表」可重新生成、增删或修改。
术语表记录目标语言；编辑保存沿用加载时条目所属的语言，重新生成成功后才随结果更新语言标记。
切换目标语言后旧条目不会被当作新语言使用；生成期间再次切换语言也保留本次请求的语言。
编辑后的条目参与缓存键，避免旧术语结果串用。AI 响应中条目的原词、译词必须为非空字符串，
备注如提供必须为字符串；格式或条目无效时最多自动重试 3 次（首次请求加 3 次重试），
取消时停止重试，重试耗尽后保留原术语表且允许下次重试。配置/网络错误不在这一层重复重试，
HTTP 限流和服务错误仍沿用请求层退避。
明确返回空数组表示没有术语，可以保存并复用；手动编辑仍会过滤未填完的空行。
共享术语表任务按书、目标语言、服务、协议、模型、地址、思考强度和密钥哈希隔离；
每个调用方独立取消等待，最后一个调用方取消时才停止底层请求；
换章后排除已取消任务，全部取消后的迟到结果不落库，旧任务收尾仅删除自身，不能干扰替代任务。

## 翻译管理

阅读设置和书籍详情均提供本书「翻译管理」入口（`/book/:id/translation`）。
管理页可展开本书配置、编辑或重新生成术语表，搜索章节并按需加载更多章节。
点击章节「重新翻译」只请求该章，绕过当前配置的缓存，忽略显示模式、折叠和预翻译章数；
未下载正文的在线章需先在阅读器取回，不在管理页拉取全书正文。
操作前重新读取章节，并推进该章租约以拒绝旧响应回填；新结果仍经过原文校验与每批 15 段限制。
成功批次覆盖当前配置的对应缓存，保留其他章和其他服务的缓存；失败或取消保留已有有效结果，
可再次点击重试。页面显示执行中、完成、失败、取消状态，离页取消在飞操作。

## 存储与失效

SQLite `user_version=4`，版本 1/2 原位新增三张表，版本 3 升级译文结构：

| 表 | 用途 |
| --- | --- |
| `translations` | 按书、章节、SHA-256 请求指纹保存原文 `source`、类型 `kind` 和译文 `text`；单次最多 15 条 |
| `translation_books` | 本书局部配置和术语表 |
| `translation_epochs` | 同正文重新获取时的版本计数，阻止在飞请求回填 |

指纹包括源文本、目标语言、服务/协议/地址/模型/思考强度、密钥哈希及术语表。
重复段落与划词共享缓存和在飞任务；读失败不降级为空缓存写回。
写入在书库锁与 SQLite 事务内校验章节正文摘要、版本计数和原文匹配关系。
正文更新与缓存清理同事务提交，只删除原文已修改或移除的译文，保留其他段落及其他服务的有效缓存。
段落按完整文本匹配，不因插入、重排、重复段落或图片变化失效；划词按仍存在的原文片段匹配，
跨段选区兼容镜像连接与原生选区换行。结构化 blocks 优先，不使用陈旧的 paragraphs 副本。
开始重取只推进版本租约；失败、取消或取回相同正文不删除有效译文，旧响应不能回填。
删除章节清除该 cid 的译文，目录重排按稳定 cid 保留；删书及身份变更沿用外键级联。
显示替换后的选区若无法在原文中匹配，仍可即时翻译，但不写入原文缓存。
切换服务保留旧服务缓存，不批量删除或预翻译整本。

版本 3 的缓存没有原文字段，无法从请求哈希可靠恢复归属；升级时仅清空这部分旧译文缓存，
书籍、局部配置和术语表保留，之后按需重新生成带原文的缓存。版本 4 之后按原文选择性清理。

全局配置通过 Rust 状态 `readerx.translation` 保存。服务请求沿用 `httpFetch` 的
原生 HTTP 通道；不记录请求、响应正文、地址或密钥，服务错误只显示状态/通用原因。
译文、本书配置、术语表及全局翻译设置不参与同步或备份；SQLite 备份快照删除三表
内容并再次 VACUUM，避免快照空闲页保留局部密钥。旧版 v1/v2 快照没有翻译表，
跳过这一步清理，继续支持旧库升级前的快照读取。

## 实现与验证

配置、协议与调度分拆在 `src/lib/translation/`；Reader 只接显示副本和交互，
`pagination.ts` 保持原文单元编号，译文片段额外携带源字符跨度。
后端命令为 `readerx_translations_get/put/invalidate`，缓存实现位于
`src-tauri/src/book_store/sqlite/translation.rs`。

`node scripts/translation-test.mjs` 覆盖指纹隔离、缓存复用、取消与版本租约、
15 段分批、并发上限、协议解析、无效响应、错误脱敏、采样及术语备注上限；
还覆盖生成术语表期间换章、旧任务收尾与新任务共享、德语不被英文短词跳过、单章强制重译、
取消重译及听书文本切换不重启显示翻译。拉丁语种缺少可靠检测时均交给服务自动判断，
可能重复请求已是目标语言的文本，以避免误跳过其他拉丁语种；
折叠模式覆盖预翻译 0/1/5 章、展开前无翻译或术语表请求、展开单段与缓存复用、
换章/在线正文到达/缓存失效保持按需、模式切换恢复预翻译及取消在飞任务。
共享术语表回归还覆盖先加入者/后加入者独立取消、继续加入与全部取消后的迟到响应。
`node scripts/glossary-test.mjs` 执行实际术语表组件的初始化/编辑/保存函数及提供商、引擎、配置模块，
覆盖切换目标语言后的保存、生成期间切换语言、无语言标记的旧表、手动空行、
畸形 AI 结果不落库、自动重试上限及最后一次成功、取消后不重试、耗尽后恢复与合法空表复用；
组件 JSX 由测试替换，不代表浏览器交互实测。
术语表另以真实组件和内存后端在 390px / 1280px 浏览器中检查保存旧语言条目、
连续三次无效响应后第四次成功、重新生成并保存新语言；AI 响应由测试夹具模拟。
`node scripts/translation-storage-test.mjs` 执行真实浏览器内存后端与原文匹配模块，覆盖
改动/删除后的选择性清理、多服务缓存保留、重取、旧租约、章节重排/删除、结构化段落与跨段选区。
SQLite Rust 回归另覆盖迁移、正文与缓存删除一起回滚、原文校验及外键级联。
`node scripts/translation-position-test.mjs` 覆盖双语滚动的实际节点采样、后续批次、
原文/译文恢复、光标 API 回退、分页节点类型及独立切换的保存与失败重试。
`node scripts/tts-replacements-test.mjs` 同时覆盖 Reader 的听书接线、两种引擎原译文切换、
预热、暂停/位置保持及取消后的迟到结果；`node scripts/tts-follow-recovery-test.mjs` 检查跟读恢复。
同时执行既有注释、章节编辑、阅读位置切换、选区定位和翻页回归。
Rust 数据检查：`cargo test --locked -p readerx --lib book_store` 和
`cargo test --locked -p readerx --lib data_transfer`（在 src-tauri 中执行）。
