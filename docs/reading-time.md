# 阅读时长统计

设置 → 阅读显示今日、近七个自然日（含今日）与累计阅读时长，按设备本地日期统计，显示精确到分钟。上线前的阅读时间不回填。

正文已加载、阅读窗口可见并聚焦时计时；切到后台、窗口失焦、离开阅读页或正文尚未就绪时暂停。阅读菜单仍属于阅读页。后台听书不计入阅读时长。计时使用单调时钟；超过五秒的计时器间隔视为设备挂起，不计入。每十五秒及暂停、离页时保存，异常终止最多可能丢失尚未保存的一段时间。

Rust 通过 `readerx_reading_time_get` / `readerx_reading_time_add` 串行读取与累加，保存在应用数据目录 `state/readerx.readingTime.json`，写入临时文件后替换。格式为 `schemaVersion: 1`、`days`（本地日期到毫秒数）、`books`（书籍 ID 到毫秒数）。旧安装缺少文件时自动从零开始；不修改书籍与阅读进度。删除书籍或重置阅读进度不会清除历史统计。统计当前仅保存在本机，不参与设备间同步。

浏览器开发模式仅保存于内存，不写 WebView 持久化存储。
