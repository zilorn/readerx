# 书签

书签按书保存在 `books.sqlite3` 的 `bookmarks` 表，记录由前端定义、后端原样存取。
定位使用稳定章节 cid + 章节镜像文本偏移；展示样式（线条 / 颜色）是可选字段。

## 目录变化后的迁移

在线书目录只做增量更新（见 [书源格式](book-source-spec.md#检查书籍更新)）：

- 仍能通过章节地址或「标题 + 卷名」对应上的章节保留原 cid、已缓存正文；
- 新增章节分配未被占用的 cid，不复用被删章节的 cid；
- 书签的 `chapterIndex` / `chapterTitle` / `chapterVolume` 随目录刷新。

旧版本曾整本覆盖目录、按新下标重排 cid，可能留下“cid 指向同下标但不同章节”的书签。
下一次「检查书籍更新」会执行一次修复，按以下证据重新确定章节：

1. cid 仍在且正文能找回书签原文（含前后文锚）→ 留在原章节；
2. cid 指向的章节标题不符时，按章节名 + 卷名查找；正文能找回原文的同名章节优先；
3. 章节名也变化时，在已缓存正文里找原文；唯一命中，或正文抽样仍大部分相似且
   标题相近时才迁移；
4. 没有任何可靠依据时保留原记录并计入未修复数，不把书签移到猜测的位置。
   这类书签可导出 JSON 后人工修正章节名 / 章节 ID / 卷名，再导入回来。

迁移后按新章节正文重新计算 `unitIndex` / `charStart` / `charEnd` / `before` / `after`，
保留书签 id、样式与创建时间。修复结果通过 `readerx_bookmarks_put` 落盘并触发同步。

## 导出 / 导入

书签面板的导出按钮把当前书的书签写成 JSON 数组，每条包含：

| 字段 | 说明 |
| --- | --- |
| `bookName` | 书名 |
| `chapterName` | 书签创建时的章节名 |
| `chapterId` | 章节稳定 cid |
| `volumeName` | 卷名；没有卷时省略字段 |
| `chapterIndex` | 章节序号（兜底定位） |
| `text` / `before` / `after` | 书签原文与前后文锚 |
| `unitIndex` / `charStart` / `charEnd` | 章内结构定位 |
| `id` / `style` / `color` / `createdAt` | 合并身份与展示样式，可选 |

导入按以下顺序重新对应章节：章节 ID（标题相符或正文能找回原文时）→
章节名 + 卷名 → 章节名 → 已缓存正文中的唯一原文命中。导入文件里仍存在的章节 ID
在标题对不上、也没有更可靠同名章节时作为兜底，便于用户手动修改 ID 后修复；
目录自动迁移不启用这条兜底。找不到可靠章节的记录跳过，不猜测落点。
已有同 `id` 的记录原位更新，缺 `id` 时同章同区间同原文视为同一条；
导入不会删除文件中没有的本地书签。

文件读写走系统文件选择器：桌面端为普通路径，Android 通过 SAF `content://` 句柄；
浏览器开发环境退回 DOM 下载 / 文件选择。上限 16 MB，内容为 UTF-8 JSON。
