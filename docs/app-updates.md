# 应用更新

设置 → 关于提供「检查更新」和「自动发现更新」。自动发现默认启用，偏好通过 Rust 状态存储持久化；启动时检查，运行期间每六小时检查，回到前台超过六小时也会检查。自动失败只记 debug 日志，手动检查失败显示错误。

更新来源为官方仓库 `zilorn/readerx` 的 GitHub `/releases/latest` 接口，只接受比当前宿主版本更高的正式语义版本，忽略草稿和预发布。没有正式 Release（404）视为没有更新。接口存在限流，网络错误允许手动重试。

新版版本号、发布说明和下载按钮显示在设置页。安装包严格按宿主系统与架构匹配现有 `scripts/collect-artifacts.mjs` 命名：Android APK、Windows setup.exe、Linux AppImage/deb/rpm。没有匹配包时提供官方发布页入口。

点击下载调用系统浏览器，由浏览器负责文件下载；应用不自动安装、重启或替换自身。Android 下载后由系统安装 APK（需允许浏览器安装来源）；桌面按所选包类型安装。更新依赖发布流程现有的签名和安装机制，不使用 Tauri updater 的签名包。

新增偏好 `readerx.autoAppUpdate`，旧数据缺少该键时默认开启，不改变既有书库格式。
