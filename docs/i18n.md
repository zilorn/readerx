# 多语言（i18n）

ReaderX 的界面支持**简体中文**（源语言）与**英语**。界面语言跟随系统，也可在
「设置 → 语言」里手动指定；偏好经 Rust 后端持久化（`readerx.locale`），WebView 不落盘。

## 目录结构

```
src/lib/i18n/
  core.ts                 纯逻辑：语言判定、占位符替换、复数选择（无 Solid / Tauri 依赖）
  index.ts                signal 接线、词典按需加载、t()、语言偏好读写
  locales/zh-CN.ts        简体中文词典汇总（源语言，MessageKey 由它推导）
  locales/en.ts           英语词典汇总（缺 key 会在编译期报错）
  locales/zh-CN/<模块>.ts  各业务模块的中文文案
  locales/en/<模块>.ts     对应模块的英文文案
```

词典**按需加载**：启动只动态 import 当前语言那一份，切换语言时再取另一份，
两份都不进首屏包体。因此 **`t()` 只能在函数 / 组件 / JSX 里调用，不能出现在模块顶层**
（模块顶层求值发生在词典载入之前，而且拿不到语言变化的响应式更新）。

## 基本用法

```tsx
import { t } from "../lib/i18n";

<button>{t("common.cancel")}</button>
<p>{t("shelf.bookCount", { count: books().length })}</p>
```

- **key 有类型**：`MessageKey` 是全部 key 的联合类型，写错 key 直接编译报错。
- **占位符**：`{name}`；中文与英文的占位符集合必须一致，`scripts/i18n-check.mjs` 会校验。
- **复数**：传 `count` 时按语言的复数规则取 `key_one` / `key_other`，取不到再退回基础 key。
  中文只写基础 key，英语在名词随数量变化时补 `_one` / `_other`：

  ```ts
  // zh-CN/shelf.ts
  "shelf.bookCount": "共 {count} 本",
  // en/shelf.ts
  "shelf.bookCount_one": "{count} book",
  "shelf.bookCount_other": "{count} books",
  ```

- **`t()` 读的是 signal**：语言一变，用到它的组件自动重新渲染，无需手动刷新。

## 模块与归属

一个业务模块一个文件，key 前缀与模块同名；`t()` 的 key 与文件对不上时，
`scripts/i18n-check.mjs` 会在「跨模块重复 key」一项里报出来。

| 模块            | 覆盖范围                                                       |
| --------------- | -------------------------------------------------------------- |
| `common`        | 跨页面复用的通用词（确定 / 取消 / 删除 / 加载中…）             |
| `shell`         | 应用外壳：文档标题、主 Tab、侧边栏、页头默认文案、404、语言偏好 |
| `settings`      | 设置页与「开源许可 / 第三方声明 / 应用日志」弹层               |
| `shelf`         | 书架、书架搜索、导入入口、书籍封面与标签                       |
| `book`          | 书籍详情、元信息编辑、分组管理                                 |
| `reader`        | 阅读页正文（菜单、目录、搜索、高亮、听书入口等）               |
| `readerChrome`  | 阅读器外壳：设置抽屉、书签面板、选区菜单、排版与进度           |
| `discover`      | 发现页：在线搜索、结果列表、书籍详情弹层、书源分组筛选         |
| `sources`       | 书源列表页：书源行、导入、测试面板、批量选择                   |
| `sourceEditor`  | 书源编辑器与其确认弹层                                         |
| `chapterRules`  | 分章规则与文本替换                                             |
| `sourceGroups`  | 书源分组的增删改与选择                                         |
| `tts`           | 听书：设置、播放、缓存、解码                                   |
| `webdav`        | WebDAV 导入与服务器管理                                        |
| `library`       | 书库读写与解析（EPUB / PDF）、日志与异常兜底                   |
| `misc`          | 尚未归类的零散文案（如全局异常兜底）                           |

`common` 只放**含义与语气都一致**的词：同一个中文词在不同语境下英文不同
（「清空」在搜索框是 Clear、在缓存页是 Delete all），这类放各自模块。

## 要翻译什么

**翻译**：用户看得见的文本 —— 按钮 / 标签 / 标题、`placeholder`、`aria-label`、`title`、
空状态、确认弹窗、Toast、`reportFailure` 与 `showToast` 的文案、传给对话框的说明文字、
Rust 命令返回错误时前端补的上下文。

**不翻译**：

- 日志（`log.info` / `warn` / `error` / `debug`）：日志是排查用的，保持中文原样，
  便于与历史日志、Rust 侧日志对照；
- 代码注释（保持中文）；
- 参与比较 / 匹配 / 持久化的字符串：正则、书源 JS 代码样例、规则名、`localStorage` /
  后端状态 key、书源字段名、`data-*` 值。某个字符串既要显示又要匹配时，
  保留匹配用的原值，另建一个只用于显示的 key；
- 中文字典 / 简繁转换相关的数据（`hanDict.ts`、`chapterRules.ts` 里的中文数字、
  「第X章」之类的模式串）。

## 迁移写法

```tsx
// ❌ 模块顶层：语言切换不会更新，词典也可能还没载入
const TABS = [{ label: "书架" }];
// ✅ 常量里存 key，渲染时再取
const TABS = [{ labelKey: "shell.tab.shelf" }] as const;
<span>{t(item.labelKey)}</span>

// ❌ 模板字符串自己拼
showToast(`已删除 ${count} 本书`);
// ✅ 占位符交给词典
showToast(t("shelf.deletedCount", { count }));
```

- 中文原文照抄进词典（除占位符替换掉动态部分），不要顺手改写文案；
- 英语：句子式大小写（sentence case）、简短直白、ASCII 直引号；
  品牌名 `ReaderX`、格式名 `EPUB` / `PDF` / `WebDAV` / `TTS` 保持原样；
- 同一句中文在多个地方出现且英文也一致时，复用同一个 key（必要时收进 `common`）；
- 不要为了 i18n 改动 DOM 结构、class、交互逻辑或注释。

## 校验

```bash
pnpm run i18n:check   # key 齐不齐、占位符一致、跨模块重复、未使用 key、漏改的中文
pnpm exec tsc --noEmit
```

`i18n:check` 的检查项：

1. `en` 是否覆盖 `zh-CN` 的全部 key（tsc 已保证，这里再兜一层）；
2. 同名 key 是否在多个模块文件里重复定义；
3. 中英占位符集合是否一致；
4. `_one` / `_other` 变体是否有对应基础 key；
5. 词典里定义了但代码里没用到的 key（提示，不失败）；
6. `src/` 里疑似漏改的硬编码中文（JSX 文本、常见属性），日志行会跳过。

## 新增一种语言

1. `core.ts` 的 `Locale` 与 `LOCALES` 加上新 tag，`detectSystemLocale` 补判定分支；
2. 复制 `locales/en/` 目录，按模块翻译，在 `locales/<tag>.ts` 里汇总；
3. `index.ts` 的 `LOADERS` 加一条 `import()`；
4. 设置页语言选项在 `src/components/LanguageRow.tsx`，语言名用该语言自身书写。

## 已知取舍

- 后端（Rust）返回的错误文案目前仍是中文：命令的 `Err(String)` 直接进 Toast。
  前端只负责自己这一层的文案，后端文案的本地化留待后续（见 `CHANGELOG.md`）。
- WebDAV、书源等用户自填内容（书名、分组名、书源名）不翻译。
