# ReaderX

基于 **Tauri 2 + SolidJS + TypeScript** 的移动端风格电子书阅读器。

## 功能

- **书架** `/`：本地书籍网格、继续阅读、阅读进度、书籍删除管理
- **发现** `/discover`：书源浏览入口（暂为空态，等接入内容）
- **导入**：书架 `+` / 空状态按钮直接选择 TXT / EPUB，解析后立即入书架，不跳页面
- **设置** `/settings`：浅色 / 深色 / 护眼三套主题、正文字号，分章规则在独立子页管理
- **阅读** `/book/:id`：章节阅读、上一章 / 下一章、目录抽屉、阅读进度跨页同步
- **听书**：阅读页点耳机图标进入听书。双引擎：**原生语音**（安卓系统 TTS，默认）与**自定义 HTTP 源**（自建 TTS 接口，返回音频字节）；悬浮球控制暂停 / 上一句 / 下一句，可调倍速（1x–3x）、音色、定时停止；正在朗读的句子在正文中实时橙色高亮（每章先读章节标题），跨章节连续朗读
- 路由页面全部**懒加载**（Vite 自动分包），Suspense 加载态
- 主题、书架进度、字号、分章规则持久化在 localStorage（键前缀 `readerx.*`）
- 书籍正文与章节存储在浏览器 IndexedDB，全程离线可用

TXT 导入时依次尝试“分章规则”匹配章节标题，未命中自动按每章约 3000 字切分；内置中文章节、序章/楔子/尾声、Chapter 等规则，也可在分章规则页添加自定义正则。

## 听书（TTS）

阅读页耳机图标进入听书：逐句朗读（每章先读标题）、上一句/下一句、暂停/继续、倍速（1x–3x）、音色、定时（分钟/本章结束）、朗读句橙色高亮并自动跟随、跨章节连续朗读；相关偏好与自定义源配置持久化（`readerx.tts`）。

### 引擎一：原生语音（默认）

安卓/桌面系统 TTS，基于社区插件 [tauri-plugin-tts](https://github.com/brenogonzaga/tauri-plugin-tts)（Rust crate `tauri-plugin-tts` + npm `tauri-plugin-tts-api`）：

- 音色来自系统已安装语音（中文优先排序），无需网络；
- 系统 TTS 无暂停 API：暂停后从当前句开头继续；
- 原生语音不会合成音频文件，因此不参与缓存。

> 桌面 Linux 编译该插件的桌面后端需要系统包 `libspeechd-dev`；若只做安卓端可忽略（安卓后端不依赖该系统库）。

### 引擎二：自定义 HTTP 源

地址与 body 里的 `{$TEXT}` 会被替换成当前朗读句文本，默认做一次 URL 编码，可用参数控制：

| 占位写法 | 效果 |
| -------- | ---- |
| `{$TEXT}` | URL 编码一次（默认） |
| `{$TEXT?URLencoding=0}` | 不编码 |
| `{$TEXT?URLencoding=2}` | 编码两次（数字可任意） |

地址与 body 里都可使用占位。POST 的 body 以 `{` 或 `[` 开头按 JSON 发送，否则按表单编码；服务端应直接返回音频字节（mp3/wav/ogg）。

| 占位写法 | 效果 |
| -------- | ---- |
| `{$RATE}` | 替换为当前倍速数值（1 / 1.5 / 2 …），由服务端**变速不变调** |

地址里用了 `{$RATE}` 时客户端以原速播放合成结果；未声明则退回客户端变速（可能有变调）。声明 `{$RATE}` 后，不同倍速的音频按不同缓存条目保存。

**预热与缓存**：播放/预取时会把合成好的句子音频按「书籍 + 声源 + 句子」持久化（`tts-audio/<bookId>/`），同一本书同一声源下次直接读缓存、不再请求服务端；阅读页停在停止状态时也会预取当前章节后续若干句用于预热，听书设置里还提供「批量预热整本书」（逐句合成写入缓存，播放开始即中止）。可在**设置 → 听书缓存**查看占用并一键清除，或按书籍清除（删除书籍时自动清理）。

> 播放采用 **WebAudio**（`decodeAudioData` + `AudioBufferSourceNode`）：无 `<audio>` 标签，暂停用 `AudioContext.suspend/resume` 可精确停在句中；「变速不变调」通过请求里的 `{$RATE}` 交给服务端实现，客户端原速播放。请确认自定义源返回 mp3 / wav / ogg 等 WebAudio 可解码的音频。

## 技术栈

| 层          | 选型                                           |
| ----------- | ---------------------------------------------- |
| UI          | SolidJS 1.9                                    |
| 路由        | @solidjs/router 1.x（JSX Route + lazy 懒加载） |
| 构建        | Vite 8 + TypeScript 6（strict）                |
| 桌面/移动壳 | Tauri 2（Rust）                                |

## 开发

```bash
pnpm install
pnpm dev            # Vite 开发服务器 → http://localhost:1420
pnpm exec tsc --noEmit   # 类型检查
pnpm build          # 前端产物构建（dist/）

pnpm tauri dev            # 桌面窗口
pnpm tauri android dev    # Android 真机/模拟器
```

详见 [AGENTS.md](./AGENTS.md)（仓库协作与代码约定）。
