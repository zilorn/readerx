# 数据实现与不可破坏的契约

下列路径以仓库根目录为起点。完整格式和流程沿用 docs，不在这里复制；以当前实现核对版本号与旧数据路径。

## 书库与稳定身份

- book_store.rs 按 books/<id>/ 拆分 bookdetail.json、content.json、bookmarks.json；digest.json 是派生指纹缓存。元信息补丁不读写整本正文，逐章回写与书签各走对应文件。新增字段核对 models.rs、BookDetail 与前端 booksTypes.ts，保留 schemaVersion 信封及字段往返测试。
- book_store 的读写入口在进程级书库事务锁内完成迁移、读取、修改、落盘及指纹更新；持锁时不调用同步引擎。单章补丁以 chapter.cid 定位，index 仅兼容旧载荷；先验证整批 cid 存在且唯一，再只改正文，保留当前目录标题/地址。
- 普通状态写入使用同目录临时文件，先 sync_all 再重命名替换，Unix（含 Android）随后同步父目录；提交前失败保留旧文件并清理临时文件，目录同步失败返回“已替换”错误（不可假定已回滚）。Windows 仅同步文件并替换，不承诺断电后的目录持久性。普通状态读写/删除与 update_state 共用事务锁；读改写必须使用 update_state 闭包，闭包内不重入状态存储或同步引擎。阅读进度经 readerx_shelf_patch 按书提交增量，ensure 仅补缺失项，reset 在后端重置当前全部记录；不要恢复成前端整份旧书架快照覆盖。
- 旧 books/<id>.json 布局迁移成功后才删旧文件，失败仍可回退读取；全库旧书签完成迁移后留 .migrated 备份。不要通过删旧数据让新布局检查通过。
- 书库与同步共用稳定 ID；已有规范 ID 沿用，不能在每次编辑后按新名字/地址重新计算。身份算法以 sync/identity.rs 为准：在线书首次按书源地址与详情页地址派生，导入书按归一文件名与字节数派生。分组与书源首次按名称/地址派生后编辑沿用 ID；规则仍按内容派生。前端 dataIds.ts 与 Rust 种子、大小写和归一化口径保持一致。
- 迁移顺序与启动入口检查 src-tauri/src/lib.rs：书籍迁移在 UI/同步访问前完成，data_ids 再处理分组、书源、规则及引用。迁移待办先落盘，每步可重跑；目录或身份冲突保留原数据并返回失败，不能覆盖目标。
- 改 ID 时检查书架进度、书签 bookId、按书规则、阅读时长及 tts-audio 目录。现有书籍迁移保留图片名，因为正文持有旧引用；不能只改目录或强行按新 ID 重命名图片。
- 隐藏分组身份为 __hidden__，不写进普通 readerx.groups；发布与落地都需识别，不能生成同名普通组。

## 备份与恢复

- 归档入口按 data_transfer/archive.rs 分类与校验条目名，拒绝越界路径；不绕过 is_safe_entry 直接解压。plan.rs 只读规划，import.rs 写盘；流式处理正文/图片，避免为整库复制字节到内存。
- 合并与覆盖语义不同：合并保留本机额外数据并按身份映射引用，偏好已有值保留；覆盖先写后删并清空归档缺失的内容类状态。新增 state 键时明确分类、合并规则、缺失语义与 ID 换算，不能直接全量 JSON 覆盖。
- 书源会话与 WebDAV 密码默认过滤，显式包含才导出；sync/、tts-audio/、logs/ 和本机 reading-time-origin 不作为换机数据搬走。阅读时长 contributions 应保留，恢复后本机新增时间使用独立来源。
- 覆盖删除书或书源前先调用同步删除钩子（定位身份仍需要旧数据），批量导入后调用 on_data_imported 全量对账。前端 import 完成后按 backup.ts 依赖顺序失效书签并重载分组、书库、进度、统计、规则、书源。
- Android SAF content:// 经 tauri-plugin-fs 打开，不能交给 std::fs 当普通路径。原生对话框在主线程弹，耗时归档 I/O 在工作线程。

## 局域网同步

- 操作日志、版本向量、因果缓冲、HLC、墓碑与冲突队列属于核心引擎；同一数据目录只允许一个写者。操作日志不能随意截断；仅写者取得目录锁后可清除未换行且无法解析的最后一行并 fsync，合法未换行尾行须保留并补换行，只读模式不修文件，已换行坏记录仍报错。未就绪或较新 schema 操作不能跳过后推进游标。本地提交与远端就绪操作均先追加日志并 fsync，再修改实体、版本向量和操作索引；追加失败时不改变这些内存状态，保留重推与缓冲重试能力。
- 字段策略看 schema.rs；LwwSilent 用于阅读位置等可丢弃旧值的数据，不能用来隐藏真正的数据冲突。改变不兼容传输语义时检查 PROTOCOL_VERSION 与能力协商，区别协议版本、本地格式版本和应用版本。
- 元信息、章节正文与封面/插图是不同通道，原书文件与听书音频不在同步范围。资源先到或关联书源未到时保留暂存，不因本机书暂缺就删资源；在线书关联恢复校验实体 uid，不凭名称或域名猜测。
- 接收包校验并暂存后实时落库，成功后才确认/推进；落库串行且游标只覆盖开始时已有操作。网络等待不占引擎锁，失败保留暂存与原游标，连接错误释放前再尝试落库。
- 停止请求处理完当前请求并保存已收数据，再关连接且不连下一设备；正常停止不报告完成或失败。进度沿用事件序号避免旧状态覆盖新事件。
- stored 是本次新存数量，重复推送可能较少；按 session.rs 现有指纹复核确认，不能仅按数量判丢数据。超大资源走 asset_transfer.rs、超大章节走 chapter_transfer.rs 分片；章节批次按完整 JSON 编码大小装箱，Hello.chapter_chunks 缺失时不发送分片请求，保留 more_content 并继续普通章节。两类分片均完整校验长度/指纹后才入暂存，连接独立的片段目录在完成、取消、断线时清理。
- 修改落库类别时同步 AppliedChanges 和 src/lib/sync.ts 的缓存重载；分组先于书库、书源分组先于书源，正文与书签需刷新已打开的书，而不只是刷新书架元数据。

## 阅读时长

- readingTime.ts 仅在正文就绪、窗口可见且聚焦时计时，使用单调时钟，挂起间隔排除，跨本地午夜拆分；离页/失焦保存并清理监听。后台听书不计入。
- reading_time.rs 串行累加并原子替换状态；contributions 是来源累计值，顶层 days/books 是显示视图。同步对同一来源、同一统计项取最大值，再对来源求和，不能把远端累计值再次作为增量相加。
- sync/reading_time.rs 发布不可变累计快照，身份含来源、统计项与累计值；保留乱序、重复、第三设备转发和旧备份重发的幂等性。来源标识 reading-time-origin 留在设备本地，书籍删除/进度重置不清历史统计。
- 旧 v1 数据迁移一次后保存；浏览器开发模式仅内存保存。统计改动检查恢复后新增来源与同步落地重载，不只检查本机计数。
